# FX 量化实验室（fxlab）

> **你正在看的是 `pages` 分支 —— 纯静态版，用 GitHub Pages 部署。**
>
> | 分支 | 形态 | 部署 | 数据来源 | 采集器 |
> |---|---|---|---|---|
> | `main` | Node 服务端 | Render / Docker / 本地 | 新浪实时 + ECB + 东财 | ✅ 支持 |
> | **`pages`（当前）** | 纯前端，无后端 | GitHub Pages | 东财实时 + ECB + 东财分钟线 | ❌ 不支持 |
>
> 两个分支的量化内核、UI、课程完全相同，差别只在「谁来抓数据、谁来算」。
> 详见第 10 节。

一个**以学习为目的**的外汇量化工作台：实时行情、指标可视化、策略回测、统计检验，全部跑在本地，零第三方依赖（只用 Node 内置模块 + 原生 Canvas）。

> 它不追求「帮你赚钱」，追求的是「让你能用证据判断一个想法值不值得下注」。

---

## 1. 快速开始

```bash
cd fxlab
node server/index.mjs
# 打开 http://127.0.0.1:8787
```

需要 Node ≥ 18（本项目在 Node 24 上验证）。**不需要 `npm install`**——没有任何依赖。

跑测试（会自动在 8799 端口起一个临时实例）：

```bash
node tests/run-all.mjs
```

## 2. 六个页面在教你什么

| 页面 | 你在这里干什么 | 对应的量化概念 |
|---|---|---|
| **市场** | 盯盘、看 16 个货币对的实时报价、点差、日内振幅 | 报价结构（bid/ask）、点差成本、波动 |
| **图表 / 指标** | 叠指标、调参数、看图形怎么变 | SMA/EMA、布林带、唐奇安通道、RSI、ATR |
| **回测实验室** | 选策略→改参数→跑→看权益曲线、回撤、交易明细 | 信号、执行时点、交易成本、绩效分解 |
| **统计体检** | 对一条价格序列做「体检」 | 收益率分布、厚尾、ACF、Hurst、ADF、VaR/ES |
| **课程** | 10 节短文，每节都指向上面能亲手验证的地方 | 定义 → 公式 → 直觉 → 陷阱 → 自测 |
| **实验记录** | 把每次回测的配置和结果存下来 | 可复现性、实验管理 |

### 建议的学习路径

1. **先建立直觉**：市场页选 EURUSD，看价格多久跳一次、点差多大、一天振幅多少。
2. **再做对照实验**：图表页把 SMA 从 (20, 60) 改成 (3, 200)，看两条线的性格差异。
3. **写下预期再回测**：回测页选「双均线」，先猜它在这个市场上会赚还是亏，再运行，对比预期。**预期与实际不符的地方，就是你要学的地方。**
4. **做减法**：把点差从 1 pip 调到 2 pip 再跑一次。如果策略立刻由盈转亏，那它本来就不该存在。
5. **看样本外**：把「样本内比例」设成 0.7，比较前后两段的夏普。差距大 = 过拟合。
6. **生成热力图**：看样本内最亮的参数格，在样本外是否还亮着。

## 3. 数据源与口径（重要）

| 源 | 内容 | 频率 | 局限 |
|---|---|---|---|
| **东方财富** `push2.eastmoney.com` | 16 个货币对实时报价（一次请求取回）+ 当日分钟线 | 秒级 | 无 52 周高低；分钟线只有当天 |
| **ECB / Frankfurter** `api.frankfurter.app` | 日线，可回溯到 1999 年 | 每工作日 1 个收盘价 | **只有收盘价**，无开高低、无成交量 |
| **新浪财经** `hq.sinajs.cn` | 实时 bid/ask（**仅 `main` 分支**） | 服务端每 3 秒轮询 | 无 CORS、校验 Referer，浏览器拿不到 |
| **内置模拟器** | GBM 随机游走（参数可复现） | 任意 | 是模型，不是市场；用来做对照实验 |

**为什么静态版不用新浪**：它的响应没有 `Access-Control-Allow-Origin`，且非 sina 域名的 Referer 一律 403，
浏览器里无论 `fetch` 还是 `<script>` 都取不到。所以 `pages` 分支统一改用东方财富——
它回显 `Origin` 并允许带凭据，实测 `Access-Control-Allow-Origin: https://opsaf.github.io`。

**采集器**：市场页点「开始采集」，服务端会把实时快照聚合成 15s / 1m / 5m K 线并落盘到 `data/bars/`。跑几天，你就有了自己的分钟级数据集——这是教科书上没有的东西。

### 三种价格不能混用

- ECB 参考价（每天定一次）
- 即期中间价（连续报价）
- 你账户里的 bid/ask（含点差）

本项目在回测中**只使用同一来源的序列**，就是为了避免把不同口径插在一起。

## 4. 回测的三条硬约定

这三条写在 `server/core/backtest.mjs` 里，改动任何一条，数字都会变：

1. **无未来函数**：第 *i* 根 K 线收盘时定仓位，吃第 *i → i+1* 根的收益（代码里是 `positions[i-1] * ret[i]`）。
2. **成本按换手收**：`cost = |Δ仓位| × 点差(pip) × pip / 价格`。没有模拟滑点，所以结果偏乐观。
3. **权益按简单收益连乘**：等价于「每期把全部本金押上」，不涉及杠杆与仓位管理。

年化因子：日线用 252，分钟线用 252×1440（因此分钟级的夏普不可与日线夏普直接比较）。

## 7. 测试与验证边界

`node tests/run-all.mjs` 会跑 4 组：

| 组 | 数量 | 验的是什么 |
|---|---|---|
| 量化内核 | 23 | 指标手算核对、无未来函数、成本口径、OLS、Hurst/ADF、聚合器 |
| 图表几何 | 8 | 用「录制型 canvas」断言蜡烛根数、坐标不越界、轴刻度方向 |
| API 接口 | 34 | 真实 HTTP 打每个端点，校验字段与数值合理性 |
| 服务端 vs 浏览器端对拍 | 14 | 同一组参数跑两条计算路径，逐字段比对（抓出过 1 根 K 线的口径差异） |
| 前端渲染（服务端模式） | 12 | Node 最小 DOM 桩，真跑 `app.js` 走完初始化与各页交互 |
| 前端渲染（静态托管模式） | 12 | 模拟没有后端，验证自动降级与浏览器直连 |

**没有验证到的**：真实浏览器里的像素级排版。本机沙箱禁止命名管道，Chrome/Edge 无法启动（`mojo platform_channel` 被拒），所以 CSS 的实际视觉效果请你在浏览器里过一眼。逻辑与数据链路已验证。

## 8. 已知局限（请当成学习材料，而不是缺陷清单）

1. **没有滑点与拒单**：实盘会更差，回测结论应打折看待。
2. **ECB 只有收盘价**：蜡烛图画不出来，只能画折线；日内策略请用东财分钟线或自采集数据。
3. **分钟线只有当天**：长期日内回测需要先积累几天数据。
4. **采集器落在单机**：进程退出后不再采集（K 线已落盘，重启后可读）。
5. **点差取快照 bid/ask 的差**，在流动性差的时段（如东京早盘）会系统性偏大。

## 9. 想继续扩展

- **加策略**：在 `server/core/strategies.mjs` 里照葫芦画瓢写 `build(bars, params)`，返回 `positions`（只能用到当根及之前的数据），前端参数面板会自动出现。
- **加数据源**：实现 `fetchXxx()` 返回 `[{date, open, high, low, close}]`，在 `core/dataset.mjs` 注册一行。
- **加指标**：`core/indicators.mjs`，约定「返回等长数组、前置 null」。
- **加课程**：`web/js/lessons.js` 里加一个对象即可。

## 10. 部署：两条路线，各取所需

### 路线 A：GitHub Pages（当前分支 `pages`，免费、无需服务器）

前端是纯静态的，数据由浏览器直连东财与 ECB，所以可以完全托管在 Pages 上。

**一次性配置**（在 GitHub 网页上操作）：

1. 仓库 → **Settings → Pages**；
2. **Source** 选 **GitHub Actions**（不要选 "Deploy from a branch"）；
3. 推到 `pages` 分支后，`.github/workflows/pages.yml` 会自动：
   同步核心模块 → 跑单元测试 → 上传 `web/` → 发布；
4. 一分钟后地址是 `https://<用户名>.github.io/Fxlab/`。

**代价**（相对服务端版）：
- 没有 SSE，改成每 5 秒轮询东财（一次请求取回 16 个货币对，流量很小）；
- 没有采集器（落盘需要常驻进程）；
- 实验记录存在浏览器 `localStorage`，换设备不同步；
- 新浪实时报价不可用（CORS 限制）。

### 路线 B：Render / Docker（`main` 分支）

`main` 分支带 `render.yaml`，New → Blueprint 选仓库即可；也可以用 `Dockerfile`。

免费实例闲置 15 分钟休眠，冷启动 30–60 秒。想随开随用，用 [cron-job.org](https://cron-job.org)
每 5 分钟 ping 一次 `/api/health`。

### 手机上的使用建议

- **亮/暗主题**：右上角按钮切换，选择记在浏览器本地；首次访问跟随系统。
- **底部导航**：窄屏自动变成底部 tab 栏，拇指可达。
- **图表手势**：轻点看某根 K 线的开高低收；竖向滑动仍是滚动页面（不会卡住）。
- **省流量**：「图表」「回测」默认只取最近几年数据，需要更长历史时改「起始日期」。

## 11. 一句话总结

> 回测不是预测未来，而是**用过去检验你的假设是否自洽**。
> 这个实验室的价值不在于它能跑出多高的夏普，而在于它能多快地把一个错误想法证伪。
